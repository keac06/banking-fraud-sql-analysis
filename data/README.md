# Dataset — PaySim Synthetic Financial Transactions

## Data Source

This project uses the PaySim synthetic financial transactions dataset, available on [Kaggle](https://www.kaggle.com/datasets/ealaxi/paysim1).

The dataset contains **6,362,620 transactions** across **744 simulated hours**, representing approximately 31 days of financial activity.

## Dataset Structure

| Column | Description |
|---|---|
| step | Simulated transaction hour |
| type | Transaction type |
| amount | Transaction amount |
| nameOrig | Originating account identifier |
| oldbalanceOrg | Originating account balance before transaction |
| newbalanceOrig | Originating account balance after transaction |
| nameDest | Destination account identifier |
| oldbalanceDest | Destination account balance before transaction |
| newbalanceDest | Destination account balance after transaction |
| isFraud | Actual fraud indicator |
| isFlaggedFraud | Fraud flag generated by the detection rule |

## Google BigQuery

The dataset was imported into Google BigQuery.

Table used in the SQL scripts:

`banking-fraud-sql-analysis.banking_fraud.transactions`

To reproduce the analyses, download the dataset from Kaggle, import it into BigQuery, and update the table reference in the SQL scripts if necessary.

## Data Availability

The full dataset is not included in this repository due to its size.

## Limitations

PaySim is a synthetic dataset. Results should not be interpreted as representative of real-world banking fraud rates.

Some account balance values may also require additional data-quality checks before interpreting accounting inconsistencies.
